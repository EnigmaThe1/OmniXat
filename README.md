# OmniXat

Commercial UK accounting, tax and compliance platform in early development.

> Early development. No tax-return preparation or official filing is implemented yet. Never commit financial records, HMRC credentials, or personal information to this public repository.

The product target includes multiple customer workspaces, subscriptions and trials,
a paid developer API, and a separate owner administration dashboard. This replaces
the earlier personal-only release strategy.

The existing [fictional prototype](prototype/README.md) is not suitable for real data
or public hosting. The new [commercial foundation](commercial/README.md) contains
the first tested internal rules, access, pricing and approval contracts; it is not
yet a deployable SaaS, payment service or filing product.

See the [commercial specification](docs/commercial/COMMERCIAL_SPEC.md) and
[UK research baseline checked 5 November 2026](docs/commercial/UK_COMPLIANCE_RESEARCH_2026-11-05.md).
